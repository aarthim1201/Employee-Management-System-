
# 👨‍💼 Employee Management System (EMS)

## 📖 About The Project
The **Employee Management System** is a robust application built to streamline and automate human resource and employee data handling. It securely connects Python with a MySQL database to perform core CRUD (Create, Read, Update, Delete) operations on employee records.

---

## 🚀 Features
* **Add New Employee:** Insert details such as Employee ID, Name, Department, Role, and Salary directly into the database.
* **View Employee Records:** Fetch and display all or specific employee details stored in the MySQL database.
* **Update Information:** Modify existing employee roles, salaries, or departments seamlessly.
* **Delete Records:** Remove inactive or resigned employee records securely.
* **Database Connectivity:** Robust backend integration using Python and MySQL.

---

## 🛠️ Built With / Tech Stack
* **Programming Language:** Python
* **Database:** MySQL
* **Libraries/Connectors:** `mysql-connector-python`
